# Security Information and Event Management (SIEM)

## Overview

A SIEM (Security Information and Event Management) system collects, analyses and correlates security data from multiple sources.

Security analysts use SIEM tools to identify suspicious activity and investigate potential threats.

---

## How SIEM Works

A SIEM platform:

1. Collects logs from systems and devices.
2. Aggregates data into a central location.
3. Analyses events for suspicious behaviour.
4. Generates alerts when threats are detected.

---

## Common Log Sources

- Firewalls
- Servers
- Endpoints
- Applications
- Network devices

---

## Benefits of SIEM

- Centralised monitoring
- Faster threat detection
- Improved incident response
- Better visibility across networks

---

## Common SIEM Tools

- Splunk
- Microsoft Sentinel
- IBM QRadar
- Elastic Security

---

## Example

A user attempts to log into an account 100 times within a few minutes.

The SIEM detects unusual activity and generates an alert for investigation.

---

## Key Takeaways

- SIEM centralises security data.
- SIEM helps detect threats.
- Security analysts rely heavily on SIEM platforms.
- SIEM improves monitoring and incident response.
